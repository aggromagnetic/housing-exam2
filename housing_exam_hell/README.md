# 🔥 주관사 2차 시험 문제지옥 (Exam Hell)

> **주택관리사보 2차 시험(관계법규, 관리실무) 3,470문항 정밀 기출 기반 실전 학습 플랫폼**

---

## 🌟 핵심 기능 및 특징

1. **5개년 기출 출제비율 100% 시뮬레이션**
   - 40문항 세트 (객관식 24문항 + 주관식 빈칸 16문항)
   - 관리실무(시설관리 39.5%, 사무인사 17% 등) 및 관계법규(주택법 20%, 공주법 20%, 건축법 17.5% 등) 실전 가중치 완벽 반영
   - 연접 유사 개념 출제 방지 (Anti-Clumping Logic) 적용

2. **5대 학습 모드**
   - 💀 **헬 모드 (무한 풀이)**: 40문항 단위로 41번, 81번... 끝없이 문제가 생성되며, 누적 오답률에 따라 **피의 게이지(Blood Gauge)**가 차오릅니다.
   - 🔄 **복습 학습 (오답 집중)**: 오답 가중치($W=2\sim 10$)가 높은 약점 문제를 룰렛 휠 확률로 우선 추출하여 집중 트레이닝합니다. (맞출 때마다 $10 \rightarrow 6 \rightarrow 4 \rightarrow 2 \rightarrow 1$ 가중치 감점)
   - ⏱️ **실전 모의고사**: 40분 카운트다운 타이머(5분 미만 경고) + OMR 마킹 시트 + AI 일타 과외 처방전 클립보드 복사
   - 📚 **파트별 전수 풀이**: 선택한 단원/법률의 객관식 및 주관식 전 문항을 무작위 순서로 100% 정복

3. **태블릿 필기 (S펜 / 애플펜슬) & 팜 리젝션**
   - PointerEvent 기반 팜 리젝션(손등 터치 무시) 지원
   - 문제 위에 반투명 필기 캔버스 제공 및 문항별 필기 데이터 IndexedDB 자동 보관

4. **IndexedDB 기반 오답 데이터베이스**
   - 3,470문항의 누적 풀이 통계, 오답 횟수, 가중치, 시험 이력을 브라우저 로컬에 안전하게 영구 보관
   - JSON 백업/복원(Export/Import) 지원

## 🚀 GitHub Pages 배포 방법

1. 본 `housing_exam_hell` 디렉토리의 파일들을 새 GitHub 레포지토리에 푸시합니다.
2. 레포지토리 `Settings` > `Pages` 이동
3. `Branch: main`, `Folder: / (root)` 선택 후 Save
4. 생성된 GitHub Pages URL로 PC 및 iPad/태블릿 브라우저에서 즉시 접속하여 학습합니다.
