주관식 단답형 및 빈칸 채우기 실전 훈련

* 다음 문장의 빈칸 내부의 각 기호(㉠, ㉡, ㉢)에 들어갈 알맞은 핵심 용어나 법정 숫자를 작성해 보십시오.

  1. 전기사업자는 사업용전기설비의 설치·변경 공사계획에 대하여 ( ㉠ )장관의 ( ㉡ )을(를) 받아야 하나, 신고 대상 공사는 공사를 시작하기 전에 허가권자에게 신고하여야 한다.
  2. 허가권자는 사용전검사에 불합격한 전기설비에 대하여 ( ㉠ )개월 이내의 범위에서 임시사용을 허용할 수 있으며, 연장 시 전체 임시사용기간은 ( ㉡ )년을 초과할 수 없다.
  3. 전기사업자가 타인의 토지를 일시 사용할 수 있는 기간은 ( ㉠ )일 이내로 한다.
  4. 화재 등 재난 발생 시 거주자의 피난활동에 적합하도록 제조된 엘리베이터를 ( ㉠ ) 엘리베이터라 하며, 주택용 엘리베이터는 ( ㉡ )주택에 설치되고 편도운행거리가 ( ㉢ )미터 이하이어야 한다.
  5. 사람의 탑승을 금지하는 ( ㉠ ) 엘리베이터(덤웨이터)는 바닥면적이 ( ㉡ )제곱미터 이하이고 높이가 ( ㉢ )미터 이하인 것은 제외한다.
  6. 승강기 제조업 또는 수입업 등록을 하려는 자는 자본금이 ( ㉠ )억원 이상이어야 하고, 유지관리업 등록을 하려는 자는 자본금이 ( ㉡ )억원 이상이어야 한다.
  7. 승강기 제조·수입업자는 부품 제공 요청을 받은 날부터 ( ㉠ )일 이내에 제공하여야 하며, 품질보증기간은 ( ㉡ )년 이상, 부품 및 가격 정보는 ( ㉢ )년 이상 홈페이지에 공개하여야 한다.
  8. 설치공사업자는 승강기 설치를 끝냈을 때에는 설치를 끝낸 날부터 ( ㉠ )일 이내에 관할 시·도지사(공단)에게 승강기 설치신고를 하여야 한다.
  9. 관리주체는 승강기 안전관리자를 선임하거나 변경한 경우 선임·변경한 날부터 ( ㉠ )일 이내에 한국승강기안전공단에 통보하여야 한다.
  10. 관리주체는 승강기 자체점검을 월 ( ㉠ )회 이상 실시하고, 점검자는 결과를 양호, ( ㉡ ), 긴급수리로 구분하여 관리주체에 통보하여야 한다.
  11. 관리주체는 자체점검 결과를 자체점검 실시일부터 ( ㉠ )일 이내에 ( ㉡ )에 입력하여야 한다.
  12. 자체점검을 담당하는 자의 승강기 실무경력 요건은 일반 승강기의 경우 ( ㉠ )년 이상이며, 정격속도가 초당 ( ㉡ )미터를 초과하는 고속 승강기는 ( ㉢ )년 이상이어야 한다.
  13. 승강기 정기검사 검사주기는 원칙적으로 1년(2년 이하)이나, 단독주택 설치 승강기 및 화물용 엘리베이터는 ( ㉠ )년이며, 설치 후 ( ㉡ )년이 경과한 승강기는 ( ㉢ )개월이다.
  14. 관리주체는 안전검사에 불합격한 승강기에 대하여 불합격한 날부터 ( ㉠ )개월 이내에 안전검사를 다시 받아야 한다.
  15. 승강기 정밀안전검사는 설치검사를 받은 날부터 ( ㉠ )년이 지난 경우에 받으며, 최초 검사 후 ( ㉡ )년마다 정기적으로 받아야 한다.
  16. ( ㉠ ) 목적으로 승강기안전인증을 면제받은 승강기는 자체점검 및 안전검사가 면제되며, 정밀안전검사를 받은 승강기는 해당 연도의 ( ㉡ )이(가) 면제된다.
